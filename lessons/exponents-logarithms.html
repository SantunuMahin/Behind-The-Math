Exponents & Logarithms

Exponents describe compounding multiplication, whereas logarithms answer the reverse question: "To what power must the base be raised to produce this number?"

The Fundamental Equivalence

Inverse Relationship

$$\log_b(x) = y \iff b^y = x$$

Change-of-base identity: $\log_b(x) = \dfrac{\ln(x)}{\ln(b)} = \dfrac{\log_{10}(x)}{\log_{10}(b)}$

Rules of Logarithms & Constraints

Key logarithmic laws:
  • Product Law: $\log_b(xy) = \log_b(x) + \log_b(y)$ (turns multiplication into addition).
  • Quotient Law: $\log_b(x/y) = \log_b(x) - \log_b(y)$.
  • Power Law: $\log_b(x^k) = k \log_b(x)$ (brings powers down to simple multipliers).
  • Domain requirement: $\log_b(x)$ is undefined for $x \le 0$ within the real numbers. $\log(0) \to -\infty$.

Worked Example

Problem

Solve for $x$ in the equation $5^{2x - 1} = 125$.

1
Express both sides using the same base.
Notice that $125 = 5^3$.
2
Equate the exponents (or take $\log_5$ of both sides).
$5^{2x - 1} = 5^3 \implies 2x - 1 = 3$.
3
Solve for $x$.
$2x = 3 + 1 = 4 \implies x = 2$.
✓ $x = 2$. (Verification: $5^{2(2)-1} = 5^{4-1} = 5^3 = 125$).

Code Examples

#include <stdio.h>
#include <math.h>

/* Computes log base b of x using change of base: log_b(x) = ln(x) / ln(b) */
double log_base(double x, double base) {
    if (x <= 0.0 || base <= 0.0 || fabs(base - 1.0) < 1e-9) {
        return NAN;
    }
    return log(x) / log(base);
}

int main(void) {
    double x = 1024.0;
    double base = 2.0;
    printf("log_%.0f(%.0f) = %.2f\n", base, x, log_base(x, base));
    return 0;
}
import math

def log_arbitrary_base(x: float, base: float = 10.0) -> float:
    """Computes log_b(x) with domain validation."""
    if x <= 0:
        raise ValueError("Log argument must be strictly positive.")
    if base <= 0 or math.isclose(base, 1.0):
        raise ValueError("Base must be positive and not equal to 1.")
    return math.log(x, base)

if __name__ == "__main__":
    print("log2(1024) =", log_arbitrary_base(1024, 2))
    print("log10(1000) =", log_arbitrary_base(1000, 10))

Check Your Understanding

Q1. What is the value of $\log_3(81)$?

Ask: 3 raised to what power equals 81? $3^1 = 3, 3^2 = 9, 3^3 = 27, 3^4 = 81$.
$3^4 = 81 \iff \log_3(81) = 4$.

Q2. For any valid base $b > 0$ ($b \ne 1$), what is $\log_b(b)$?

What power turns $b$ into $b^1$?
Since $b^1 = b$, $\log_b(b) = 1$. Similarly, $b^0 = 1 \implies \log_b(1) = 0$.

Q3. If $\log(x) + \log(y) = \log(k)$, what is $k$?

Recall the logarithm product property: adding logs multiplies the arguments.
By the product law of logarithms: $\log(x) + \log(y) = \log(xy)$. So $k = x \cdot y$.
