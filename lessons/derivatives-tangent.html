Derivatives & Tangent Slope

How do you define the exact speed of a car at a single instant in time? You cannot divide distance 0 by elapsed time 0. The derivative solves this foundational puzzle by taking the limit of average slopes as the time interval shrinks toward zero.

The Limit Definition of Derivative

First Principle of Differentiation

$$f'(x) = \lim_{h \to 0} \dfrac{f(x+h) - f(x)}{h} = \dfrac{df}{dx}$$

Geometrically, this represents the instantaneous slope of the tangent line touching the curve $y = f(x)$ at $x$.

Symbol Definitions

SymbolMeaningDomain / Constraint
f(x)Original differentiable functionDomain of $f$
xEvaluation point along the input axisInterior point where limit exists
h (or Δx)Step size (distance between secant points)Approaches 0, $h \neq 0$
f'(x)Derivative (instantaneous rate of change / tangent slope)Slope value ($m = \tan \theta$)

Differentiability Conditions

When a derivative exists:
  • Continuity is necessary: If $f(x)$ has a jump, hole, or asymptote at $x$, it is not differentiable.
  • No sharp corners or cusps: For example, $f(x) = |x|$ is continuous everywhere, but has no derivative at $x = 0$ because the left slope is $-1$ while the right slope is $+1$.
  • No vertical tangents: If the tangent line becomes vertical (slope $\to \infty$), the derivative is undefined.

Worked Example

Problem

Prove from first principles that the derivative of $f(x) = x^2$ is $f'(x) = 2x$.

1
Set up the difference quotient.
$\dfrac{f(x+h) - f(x)}{h} = \dfrac{(x+h)^2 - x^2}{h}$.
2
Expand the binomial.
$\dfrac{x^2 + 2xh + h^2 - x^2}{h} = \dfrac{2xh + h^2}{h}$.
3
Cancel $h$ ($h \neq 0$).
$\dfrac{h(2x + h)}{h} = 2x + h$.
4
Evaluate the limit as $h \to 0$.
$\lim_{h \to 0} (2x + h) = 2x + 0 = 2x$.
✓ Therefore $\dfrac{d}{dx}[x^2] = 2x$. At $x = 3$, the tangent slope is exactly $2(3) = 6$.

Code Examples

Numerical differentiation using central differences $O(h^2)$ precision.

#include <stdio.h>
#include <math.h>

/* Central difference approximation: [f(x+h) - f(x-h)] / (2h) */
double numerical_derivative(double (*f)(double), double x, double h) {
    return (f(x + h) - f(x - h)) / (2.0 * h);
}

double square(double x) { return x * x; }

int main(void) {
    double x = 2.0;
    double df = numerical_derivative(square, x, 1e-5);
    printf("Numerical derivative of x^2 at x = %.1f is %.5f\n", x, df);
    return 0;
}
from typing import Callable
import math

def central_difference(f: Callable[[float], float], x: float, h: float = 1e-6) -> float:
    """Approximates f'(x) using symmetric difference quotient."""
    return (f(x + h) - f(x - h)) / (2 * h)

if __name__ == "__main__":
    f = lambda x: x**2
    print("Derivative of x^2 at x = 2.0:", central_difference(f, 2.0))
    print("Derivative of sin(x) at x = 0.0:", central_difference(math.sin, 0.0))

Check Your Understanding

Q1. If $f(x) = x^2$, what is the instantaneous slope of the tangent line at $x = 3$?

The derivative is $f'(x) = 2x$. Evaluate at $x = 3$.
$f'(x) = 2x \implies f'(3) = 2 \times 3 = 6$. The tangent line has slope $m = 6$.

Q2. At a local peak (maximum) or valley (minimum) of a smooth differentiable curve, the tangent slope is always:

At the very top of a roller coaster hill, is the track going up or down?
By Fermat's theorem on stationary points, smooth extrema have zero rate of change: $f'(x) = 0$.

Q3. Why does the calculus identity $\frac{d}{dx}[\sin(x)] = \cos(x)$ require $x$ to be measured in radians rather than degrees?

In degrees, an extra scaling factor of $\pi / 180$ must be multiplied!
In radians, the arc length equals radius $\times$ angle, making $\lim_{\theta \to 0}\frac{\sin \theta}{\theta} = 1$. In degrees, $\frac{d}{dx}[\sin(x^\circ)] = \frac{\pi}{180}\cos(x^\circ)$.
