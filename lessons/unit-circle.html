Trigonometric Unit Circle

Move beyond right-angled triangles to define trigonometric functions for any angle from 0° to 360° and beyond. On a circle of radius 1, cosine is simply the x-coordinate, and sine is the y-coordinate.

The Fundamental Identity

Pythagorean Trigonometric Identity

$$\sin^2\theta + \cos^2\theta = 1$$ $$\tan\theta = \dfrac{\sin\theta}{\cos\theta}$$

On the unit circle ($r = 1$), the right triangle satisfies $x^2 + y^2 = 1^2 \implies \cos^2\theta + \sin^2\theta = 1$.

Symbol Definitions

SymbolMeaningDomain / Range
θ (theta)Angle measured counter-clockwise from positive x-axis$\theta \in \mathbb{R}$ (degrees or radians)
cos(θ)Horizontal coordinate $x$ on the unit circle$-1 \le \cos\theta \le 1$
sin(θ)Vertical coordinate $y$ on the unit circle$-1 \le \sin\theta \le 1$
tan(θ)Slope of the radius line: $\sin\theta / \cos\theta$Undefined when $\cos\theta = 0$ ($\theta = 90^\circ, 270^\circ$)

Four-Quadrant Signs (ASTC Rule)

Signs across quadrants:
  • Quadrant I (0° to 90°): All functions (sin, cos, tan) are positive.
  • Quadrant II (90° to 180°): Only Sine is positive ($y > 0, x < 0$).
  • Quadrant III (180° to 270°): Only Tangent is positive ($y < 0, x < 0 \implies y/x > 0$).
  • Quadrant IV (270° to 360°): Only Cosine is positive ($x > 0, y < 0$).

Worked Example

Problem

Find $\sin(150^\circ)$, $\cos(150^\circ)$, and $\tan(150^\circ)$ without a calculator.

1
Identify the quadrant and reference angle.
$150^\circ$ is in Quadrant II ($90^\circ < 150^\circ < 180^\circ$). The reference angle is $180^\circ - 150^\circ = 30^\circ$.
2
Recall values for 30°.
$\sin(30^\circ) = 1/2 = 0.5$, $\cos(30^\circ) = \sqrt{3}/2 \approx 0.866$, $\tan(30^\circ) = 1/\sqrt{3} \approx 0.577$.
3
Apply Quadrant II signs (only Sine is positive).
$\sin(150^\circ) = +1/2 = +0.5$.
$\cos(150^\circ) = -\sqrt{3}/2 \approx -0.866$.
$\tan(150^\circ) = -1/\sqrt{3} \approx -0.577$.
✓ $\sin(150^\circ) = 0.5$, $\cos(150^\circ) = -\sqrt{3}/2$, $\tan(150^\circ) = -1/\sqrt{3}$. Notice: $(0.5)^2 + (-\sqrt{3}/2)^2 = 0.25 + 0.75 = 1$.

Code Examples

#include <stdio.h>
#include <math.h>

int main(void) {
    const double pi = 3.141592653589793;
    double angle_deg = 150.0;
    double angle_rad = angle_deg * (pi / 180.0);

    double s = sin(angle_rad);
    double c = cos(angle_rad);
    double t = tan(angle_rad);

    printf("sin(%.0f°) = %.4f\n", angle_deg, s);
    printf("cos(%.0f°) = %.4f\n", angle_deg, c);
    printf("tan(%.0f°) = %.4f\n", angle_deg, t);
    printf("Identity check: s^2 + c^2 = %.6f\n", s*s + c*c);
    return 0;
}
import math

def trig_circle(deg: float):
    rad = math.radians(deg)
    s = math.sin(rad)
    c = math.cos(rad)
    identity = s**2 + c**2
    return {"sin": s, "cos": c, "identity": identity}

if __name__ == "__main__":
    res = trig_circle(150.0)
    print(f"sin(150°) = {res['sin']:.4f}")
    print(f"cos(150°) = {res['cos']:.4f}")
    print(f"sin² + cos² = {res['identity']:.6f}")

Check Your Understanding

Q1. For ANY real angle $\theta$, what is the exact value of $\sin^2\theta + \cos^2\theta$?

Recall the equation of a circle of radius 1: $x^2 + y^2 = 1$.
Because any point on the unit circle satisfies $x^2 + y^2 = 1$ with $x = \cos\theta$ and $y = \sin\theta$, $\cos^2\theta + \sin^2\theta = 1$ is an absolute identity.

Q2. What is $\cos(180^\circ)$ (or $\cos(\pi)$)?

At 180°, the point on the unit circle lies on the far left of the x-axis: $(-1, 0)$.
At $180^\circ$, coordinate $(x, y) = (-1, 0)$. Therefore $\cos(180^\circ) = -1$ and $\sin(180^\circ) = 0$.

Q3. Why is $\tan(90^\circ)$ undefined?

$\tan\theta = \sin\theta / \cos\theta$. What is the denominator at 90°?
At $90^\circ$, $\cos(90^\circ) = 0$. Since $\tan = \sin / \cos$, calculating $\tan(90^\circ)$ requires dividing by zero (a vertical tangent line).
