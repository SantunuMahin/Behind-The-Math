Pythagorean Theorem

The cornerstone of Euclidean distance. In any right-angled triangle, the area of the square constructed on the hypotenuse is exactly equal to the sum of the areas of the squares on the other two legs.

The Formula

Relationship between legs and hypotenuse

$$a^2 + b^2 = c^2 \implies c = \sqrt{a^2 + b^2}$$

where a and b are perpendicular legs, and c is the hypotenuse opposite the 90° angle.

Symbol Definitions

SymbolMeaningUnitConstraint
aLength of the first perpendicular leg (base)lengtha > 0
bLength of second perpendicular leg (altitude)lengthb > 0
cHypotenuse (side opposite right angle)lengthc = √(a² + b²) > max(a, b)
θAngle between side a and hypotenuse cdegrees / radians0° < θ < 90°

Conditions & Assumptions

Applicability rules:
  • The triangle must contain a 90° right angle. If all angles differ from 90°, you must use the Law of Cosines: $c^2 = a^2 + b^2 - 2ab\cos(C)$.
  • Valid in flat Euclidean space. On a sphere, triangles can have three 90° angles ($a^2 + b^2 > c^2$).
  • Lengths $a, b, c$ must be positive real numbers.

Plain-Language & Visual Intuition

Imagine building literal square tiles off each of the three sides of a right triangle. If you fill the square on leg $a$ (area $a^2$) and the square on leg $b$ (area $b^2$) with sand or water, their combined volume will fill the square built on hypotenuse $c$ (area $c^2$) with zero residue left over.

The Euclidean Distance Formula: The distance between two points $(x_1, y_1)$ and $(x_2, y_2)$ on a 2D plane is direct Pythagoras: $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$. Everything from computer graphics to GPS relies on this.

Worked Example

Problem

A 13-meter ladder leans against a vertical wall. The base of the ladder is 5 meters away from the wall. How high up the wall does the ladder reach?

1
Identify hypotenuse and legs.
The ladder is the hypotenuse: $c = 13$ m. The base distance is leg $a = 5$ m. The vertical wall height is leg $b$.
2
Rearrange the Pythagorean equation for leg b.
$b^2 = c^2 - a^2 \implies b = \sqrt{c^2 - a^2}$
3
Substitute the numbers.
$b = \sqrt{13^2 - 5^2} = \sqrt{169 - 25} = \sqrt{144} = 12$ meters.
✓ The ladder reaches 12 meters up the wall (a classic (5, 12, 13) Pythagorean triple).

Code Examples

Implementations computing the hypotenuse and validating inputs against non-positive sides.

#include <stdio.h>
#include <math.h>

/* Computes hypotenuse c given legs a and b */
double pythagoras(double a, double b) {
    if (a <= 0.0 || b <= 0.0) {
        fprintf(stderr, "Error: sides must be positive real numbers.\n");
        return -1.0;
    }
    /* hypot() handles potential intermediate overflow safely */
    return hypot(a, b);
}

int main(void) {
    double a = 3.0, b = 4.0;
    double c = pythagoras(a, b);
    printf("Legs %.2f and %.2f -> Hypotenuse c = %.2f\n", a, b, c);
    return 0;
}
import math

def hypotenuse(a: float, b: float) -> float:
    """Calculates the hypotenuse c = sqrt(a^2 + b^2)."""
    if a <= 0 or b <= 0:
        raise ValueError("Triangle side lengths must be strictly positive.")
    return math.hypot(a, b)

if __name__ == "__main__":
    leg_a, leg_b = 5.0, 12.0
    c = hypotenuse(leg_a, leg_b)
    print(f"Legs {leg_a} and {leg_b} -> Hypotenuse c = {c:.2f}")
    # Output: Legs 5.0 and 12.0 -> Hypotenuse c = 13.00

Check Your Understanding

Q1. A right triangle has legs of length $a = 6$ cm and $b = 8$ cm. What is the length of its hypotenuse $c$?

Calculate $6^2 + 8^2 = 36 + 64$. Then find $\sqrt{100}$.
$\sqrt{6^2 + 8^2} = \sqrt{36 + 64} = \sqrt{100} = 10$. This is double the base $(3, 4, 5)$ Pythagorean triple.

Q2. Can a triangle with side lengths 7, 10, and 12 be a right-angled triangle?

Test if $7^2 + 10^2$ equals $12^2$: $49 + 100 = 149$, whereas $12^2 = 144$.
$7^2 + 10^2 = 149 \neq 144 = 12^2$. Since $a^2 + b^2 \neq c^2$, it cannot be a right triangle (in fact, since $149 > 144$, it is an acute triangle).

Q3. A right triangle has hypotenuse $c = 17$ and one leg $a = 8$. What is the length of the other leg $b$?

Rearrange to $b = \sqrt{c^2 - a^2} = \sqrt{17^2 - 8^2} = \sqrt{289 - 64}$.
$b = \sqrt{289 - 64} = \sqrt{225} = 15$. The set $(8, 15, 17)$ is a well-known Pythagorean triple.
