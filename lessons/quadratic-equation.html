Quadratic Formula

Finding where a parabola crosses the horizontal axis is one of algebra's deepest tools. The quadratic formula computes both roots directly from the equation's coefficients.

The Formula

Roots of ax² + bx + c = 0

$$x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

where $\Delta = b^2 - 4ac$ is the discriminant, determining the number and nature of roots.

Symbol Definitions

SymbolMeaningDomain / Constraint
aLeading quadratic coefficienta ≠ 0 (if a = 0, the equation is linear)
bLinear coefficientReal number (b ∈ ℝ)
cConstant term (vertical y-intercept)Real number (c ∈ ℝ)
Δ (Delta)Discriminant: b² - 4ac> 0: two real roots; = 0: one repeated root; < 0: two complex roots
x_vVertex x-coordinate (-b / 2a)Axis of symmetry of the parabola

Conditions & Assumptions

Key mathematical properties:
  • $a \neq 0$: If $a = 0$, dividing by $2a$ results in division by zero; the equation collapses to the linear form $bx + c = 0$, giving single root $x = -c/b$.
  • Discriminant test:
    • $\Delta > 0$: Parabola intersects the x-axis at two distinct real points.
    • $\Delta = 0$: Parabola's vertex touches the x-axis at one repeated root $x = -b/(2a)$.
    • $\Delta < 0$: Parabola never intersects the x-axis; roots are a pair of complex conjugates.

Worked Example

Problem

Solve the quadratic equation $2x^2 - 4x - 6 = 0$.

1
Identify coefficients.
$a = 2$, $b = -4$, $c = -6$.
2
Compute the discriminant.
$\Delta = b^2 - 4ac = (-4)^2 - 4(2)(-6) = 16 - (-48) = 16 + 48 = 64$.
3
Take the square root.
$\sqrt{64} = 8$. Since $\Delta > 0$, there are two real roots.
4
Apply the quadratic formula.
$x = \dfrac{-(-4) \pm 8}{2(2)} = \dfrac{4 \pm 8}{4}$.
• $x_1 = (4 + 8) / 4 = 12 / 4 = 3$
• $x_2 = (4 - 8) / 4 = -4 / 4 = -1$.
✓ The roots are $x = 3$ and $x = -1$. (Check: $2(3)^2 - 4(3) - 6 = 18 - 12 - 6 = 0$).

Code Examples

Production-grade solutions handling $a = 0$, positive, zero, and negative discriminants.

#include <stdio.h>
#include <math.h>

void solve_quadratic(double a, double b, double c) {
    if (fabs(a) < 1e-9) {
        if (fabs(b) < 1e-9) {
            printf("No solution or infinite solutions.\n");
        } else {
            printf("Linear equation: x = %.4f\n", -c / b);
        }
        return;
    }

    double disc = b * b - 4.0 * a * c;
    if (disc > 0.0) {
        double sqrt_d = sqrt(disc);
        double x1 = (-b + sqrt_d) / (2.0 * a);
        double x2 = (-b - sqrt_d) / (2.0 * a);
        printf("Two real roots: x1 = %.4f, x2 = %.4f\n", x1, x2);
    } else if (fabs(disc) < 1e-9) {
        double x = -b / (2.0 * a);
        printf("One repeated real root: x = %.4f\n", x);
    } else {
        double real_part = -b / (2.0 * a);
        double imag_part = sqrt(-disc) / (2.0 * a);
        printf("Complex roots: %.4f ± %.4fi\n", real_part, fabs(imag_part));
    }
}

int main(void) {
    solve_quadratic(2.0, -4.0, -6.0);
    return 0;
}
import cmath
import math

def solve_quadratic(a: float, b: float, c: float):
    """Solves ax^2 + bx + c = 0 for all real or complex roots."""
    if math.isclose(a, 0.0):
        if math.isclose(b, 0.0):
            return "Indeterminate or contradictory"
        return (-c / b,)

    disc = b**2 - 4 * a * c
    if disc > 0:
        sqrt_d = math.sqrt(disc)
        x1 = (-b + sqrt_d) / (2 * a)
        x2 = (-b - sqrt_d) / (2 * a)
        return (x1, x2)
    elif math.isclose(disc, 0.0):
        return (-b / (2 * a),)
    else:
        sqrt_d = cmath.sqrt(disc)
        x1 = (-b + sqrt_d) / (2 * a)
        x2 = (-b - sqrt_d) / (2 * a)
        return (x1, x2)

if __name__ == "__main__":
    print("Roots of 2x^2 - 4x - 6 = 0:", solve_quadratic(2, -4, -6))
    # Output: (3.0, -1.0)

Check Your Understanding

Q1. How many distinct real roots does the equation $x^2 - 6x + 9 = 0$ have?

Calculate the discriminant: $\Delta = (-6)^2 - 4(1)(9) = 36 - 36$.
$\Delta = 36 - 36 = 0$. When $\Delta = 0$, the parabola's vertex touches the x-axis, creating exactly 1 repeated root at $x = 3$.

Q2. What is the discriminant $\Delta = b^2 - 4ac$ for the equation $x^2 + 2x + 2 = 0$?

Plug into $b^2 - 4ac$: $a = 1$, $b = 2$, $c = 2$.
$\Delta = 2^2 - 4(1)(2) = 4 - 8 = -4$. Because $\Delta < 0$, roots are complex conjugates: $x = -1 \pm i$.

Q3. At what x-coordinate does the axis of symmetry / vertex lie for $y = 3x^2 - 12x + 7$?

The vertex x-coordinate is given by $x = -b / (2a)$.
$x = -(-12) / (2 \times 3) = 12 / 6 = 2$. The parabola is vertically symmetric around the line $x = 2$.
