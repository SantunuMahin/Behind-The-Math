Percentages & Ratios

Percentages normalize proportions to a standard base of 100 ("per centum"). Ratios express relative scale between distinct quantities. Together, they power financial calculations, data science, and everyday comparisons.

The Formulas

Proportion & Percentage Change

$$P = \dfrac{\text{Part}}{\text{Whole}} \times 100\% \qquad \Delta\% = \dfrac{x_{\text{new}} - x_{\text{old}}}{x_{\text{old}}} \times 100\%$$

And for a ratio $a : b$, the fractional share of $a$ is $\dfrac{a}{a + b}$.

Symbol Definitions

SymbolMeaningDomain / Constraints
PartSubset quantity under examinationReal number
WholeTotal reference quantityWhole ≠ 0
PPercentage representationUsually 0% to 100% (can exceed 100% for growth)
Δ%Relative percentage increase or decreaseNegative for decrease, positive for increase
a : bPart-to-part ratio$a, b > 0$

Conditions & Common Pitfalls

Critical rules to remember:
  • Asymmetry of percentage change: If a price drops by 50% from $100 to $50, it requires a 100% increase (from $50 back to $100) to return to its original value, not 50%!
  • Zero baseline: You cannot calculate percentage change from a starting value of $x_{\text{old}} = 0$ (division by zero).
  • Percentage points vs. Percent change: Moving from 10% to 12% is an increase of 2 percentage points, but a 20% relative increase.

Worked Example

Problem

A stock was originally priced at $80. It increases to $104. What is the percentage increase?

1
Identify old and new values.
$x_{\text{old}} = 80$, $x_{\text{new}} = 104$.
2
Calculate the absolute increase.
$104 - 80 = +24$.
3
Divide by the original value.
$\dfrac{24}{80} = 0.30$.
4
Multiply by 100 to get percentage.
$0.30 \times 100\% = 30\%$.
✓ The stock experienced a 30% price increase.

Code Examples

#include <stdio.h>
#include <math.h>

double calc_percentage(double part, double whole) {
    if (fabs(whole) < 1e-9) return 0.0;
    return (part / whole) * 100.0;
}

double percentage_change(double old_val, double new_val) {
    if (fabs(old_val) < 1e-9) return 0.0;
    return ((new_val - old_val) / old_val) * 100.0;
}

int main(void) {
    printf("35 out of 100 = %.2f%%\n", calc_percentage(35.0, 100.0));
    printf("Change 80 -> 104 = %.2f%%\n", percentage_change(80.0, 104.0));
    return 0;
}
def percentage(part: float, whole: float) -> float:
    if whole == 0:
        raise ZeroDivisionError("Denominator cannot be zero.")
    return (part / whole) * 100

def percentage_change(old: float, new: float) -> float:
    if old == 0:
        raise ZeroDivisionError("Baseline value cannot be zero.")
    return ((new - old) / old) * 100

if __name__ == "__main__":
    print(f"80 to 104 is a {percentage_change(80, 104):.1f}% change")
    # Output: 80 to 104 is a 30.0% change

Check Your Understanding

Q1. A class has 30 boys and 10 girls. What percentage of the class are girls?

The Whole is the total number of students: $30 + 10 = 40$.
Part / Whole $= 10 / 40 = 1 / 4 = 0.25 = 25\%$. Always remember to sum all parts to find the denominator.

Q2. An item drops 50% in price. By what percentage must the new price increase to return to the original price?

If price was $100, a 50% drop makes it $50. To go from $50 back to $100, how much must it gain relative to $50?
$\Delta\% = (100 - 50) / 50 \times 100\% = 50 / 50 \times 100\% = 100\%$. The base for the increase is now smaller!

Q3. If $a : b = 3 : 7$ and total sum $a + b = 100$, what is the value of $a$?

Total parts $= 3 + 7 = 10$. Then $a = \frac{3}{10} \times 100$.
$a = \frac{3}{3 + 7} \times 100 = \frac{3}{10} \times 100 = 30$.
