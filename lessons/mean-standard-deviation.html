Mean & Standard Deviation

Two datasets can have the exact same average yet behave completely differently. While the mean gives the center of balance, standard deviation measures how tightly or widely the values cluster around that center.

The Formulas

Center & Spread

$$\mu = \dfrac{1}{N}\sum_{i=1}^N x_i$$ $$\sigma = \sqrt{\dfrac{\sum(x_i - \mu)^2}{N}} \qquad s = \sqrt{\dfrac{\sum(x_i - \bar{x})^2}{n-1}}$$

Use $\sigma$ (divided by $N$) for a complete population; use $s$ (divided by $n-1$, Bessel's correction) for an estimated sample.

Symbol Definitions

SymbolMeaningDomain / Constraints
x_iIndividual observation data pointReal number ($x_i \in \mathbb{R}$)
N (or n)Total count of data points in datasetInteger $\ge 1$ (for sample s, $n \ge 2$)
μ (or x̄)Arithmetic Mean (average)Same unit as $x$
σ² (or s²)Variance (average squared deviation)Units squared
σ (or s)Standard Deviation (square root of variance)Non-negative ($\ge 0$), same unit as $x$

Why Bessel's Correction (n - 1)?

Sample vs Population:

When computing deviations from a sample mean $\bar{x}$ instead of the true population mean $\mu$, the deviations are systematically slightly smaller because $\bar{x}$ was chosen to minimize the sum of squared distances to that specific sample. Dividing by $n-1$ instead of $n$ un-biases the estimator, preventing systematic underestimation of the true variance.

Worked Examples & Real-World Math

Example 1 · Population Standard Deviation ($\sigma$)

Find the mean and population standard deviation of the numbers: 2, 4, 4, 4, 5, 5, 7, 9.

1
Calculate the sum and mean.
Sum $= 2 + 4 + 4 + 4 + 5 + 5 + 7 + 9 = 40$.
Count $N = 8$.
Mean $\mu = 40 / 8 = 5.0$.
2
Calculate squared deviations $(x_i - \mu)^2$.
$(2-5)^2 = 9$
$(4-5)^2 = 1$ (occurs three times $\implies 3 \times 1 = 3$)
$(5-5)^2 = 0$ (occurs twice $\implies 0$)
$(7-5)^2 = 4$
$(9-5)^2 = 16$.
3
Sum squared deviations and divide by N.
Sum of squares $= 9 + 3 + 0 + 4 + 16 = 32$.
Population Variance $\sigma^2 = 32 / 8 = 4.0$.
4
Take the square root.
$\sigma = \sqrt{4.0} = 2.0$.
✓ Mean $\mu = 5.0$ · Population Standard Deviation $\sigma = 2.0$.

Example 2 · Sample Standard Deviation & Bessel's Correction ($n - 1$)

A quality control engineer draws a small random sample of $n = 5$ precision resistors with resistances: $98\,\Omega, 100\,\Omega, 101\,\Omega, 102\,\Omega, 104\,\Omega$. Compute the sample mean $\bar{x}$ and unbiased sample standard deviation $s$.

1
Calculate sample mean ($\bar{x}$).
$\bar{x} = \dfrac{98 + 100 + 101 + 102 + 104}{5} = \dfrac{505}{5} = 101.0\,\Omega$.
2
Compute squared deviations from sample mean.
$(98 - 101)^2 = (-3)^2 = 9$
$(100 - 101)^2 = (-1)^2 = 1$
$(101 - 101)^2 = 0^2 = 0$
$(102 - 101)^2 = 1^2 = 1$
$(104 - 101)^2 = 3^2 = 9$.
$\sum (x_i - \bar{x})^2 = 9 + 1 + 0 + 1 + 9 = 20.0$.
3
Apply Bessel's correction (divide by $n - 1 = 4$).
Why $n-1$? Sample variance using $N$ systematically underestimates true population variance because sample data clusters around $\bar{x}$ closer than true $\mu$. Dividing by $n-1$ removes this statistical bias.
Sample variance $s^2 = \dfrac{20.0}{5 - 1} = \dfrac{20.0}{4} = 5.0\,\Omega^2$.
4
Take the square root for sample standard deviation.
$s = \sqrt{5.0} \approx 2.236\,\Omega$.
✓ Unbiased Sample Mean $\bar{x} = 101.0\,\Omega$ · Sample Standard Deviation $s \approx 2.24\,\Omega$. Notice that without Bessel's correction, dividing by $5$ would yield $\sqrt{4} = 2.0$, underestimating real batch variability!

Code Examples

#include <stdio.h>
#include <math.h>

void calc_stats(const double arr[], int n) {
    if (n <= 0) return;
    double sum = 0.0;
    for (int i = 0; i < n; i++) sum += arr[i];
    double mean = sum / n;

    double sq_diff_sum = 0.0;
    for (int i = 0; i < n; i++) {
        double diff = arr[i] - mean;
        sq_diff_sum += diff * diff;
    }

    double pop_sd = sqrt(sq_diff_sum / n);
    double sample_sd = n > 1 ? sqrt(sq_diff_sum / (n - 1)) : 0.0;

    printf("Mean: %.2f\n", mean);
    printf("Population SD (N): %.2f\n", pop_sd);
    printf("Sample SD (N-1):   %.2f\n", sample_sd);
}

int main(void) {
    double data[] = {2, 4, 4, 4, 5, 5, 7, 9};
    calc_stats(data, 8);
    return 0;
}
import statistics

def analyze_data(data: list[float]):
    mean = statistics.mean(data)
    pop_sd = statistics.pstdev(data)   # N divisor
    sample_sd = statistics.stdev(data)  # n-1 divisor (Bessel's correction)
    return {"mean": mean, "pop_sd": pop_sd, "sample_sd": sample_sd}

if __name__ == "__main__":
    dataset = [2, 4, 4, 4, 5, 5, 7, 9]
    stats = analyze_data(dataset)
    print(f"Mean: {stats['mean']:.2f}")
    print(f"Population SD: {stats['pop_sd']:.2f}")
    print(f"Sample SD (N-1): {stats['sample_sd']:.2f}")

Check Your Understanding

Q1. If all numbers in a dataset are identical (e.g. [5, 5, 5, 5]), what is the standard deviation?

Each deviation $(x_i - \mu)$ is $5 - 5 = 0$.
Since there is zero spread or dispersion around the mean, the standard deviation is exactly 0.

Q2. What is the mathematical relationship between variance and standard deviation?

Recall that variance is $\sigma^2$ and standard deviation is $\sigma$.
Standard deviation is $\sigma = \sqrt{\sigma^2}$. Taking the square root brings the units back to the original measurement scale.

Q3. Why do we divide by $n - 1$ instead of $n$ when calculating the sample standard deviation?

Recall Bessel's correction for sample variance estimation.
Bessel's correction ($n-1$) accounts for the fact that sample deviations from $\bar{x}$ are slightly tighter than deviations from the true unknown population mean $\mu$.
