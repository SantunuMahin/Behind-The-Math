Probability & Bayes' Theorem

How should you update your beliefs in light of new evidence? Bayes' Theorem provides the mathematical engine for rational belief updating, machine learning classification, and medical diagnostic reasoning.

The Formula

Bayes' Rule of Conditional Inference

$$P(A|B) = \dfrac{P(B|A)\,P(A)}{P(B)} = \dfrac{P(B|A)\,P(A)}{P(B|A)P(A) + P(B|\neg A)P(\neg A)}$$

Posterior = (Likelihood × Prior) / Marginal Probability of Evidence.

Symbol Definitions

SymbolMeaningDomain / Constraint
P(A)Prior Probability: Initial belief that hypothesis A is true before evidence$0 \le P(A) \le 1$
P(B|A)Likelihood: Probability that evidence B occurs if hypothesis A is true$0 \le P(B|A) \le 1$
P(B)Marginal Evidence: Total probability of observing evidence B under all scenarios$P(B) > 0$
P(A|B)Posterior Probability: Updated belief in hypothesis A after observing evidence B$0 \le P(A|B) \le 1$

The Base Rate Fallacy

Why intuition fails:

Humans routinely ignore the prior base rate $P(A)$. If a disease affects only 1 in 1,000 people ($P(A) = 0.1\%$), even a medical test with 99% accuracy will produce far more false positives than true positives among the general population!

Worked Example

Problem

1% of a population has a disease ($P(A) = 0.01$). A test has a 99% true-positive rate ($P(B|A) = 0.99$) and a 5% false-positive rate ($P(B|\neg A) = 0.05$). A patient tests positive. What is the probability they actually have the disease?

1
Calculate the probability of healthy patients.
$P(\neg A) = 1 - 0.01 = 0.99$.
2
Calculate the total marginal probability of a positive test $P(B)$.
$P(B) = (0.99 \times 0.01) + (0.05 \times 0.99) = 0.0099 + 0.0495 = 0.0594$.
3
Apply Bayes' formula.
$P(A|B) = \dfrac{0.0099}{0.0594} \approx 0.1667 = 16.67\%$.
✓ Despite a 99% accurate test, there is only a 16.67% chance the patient has the disease because of the low base rate.

Code Examples

#include <stdio.h>

/* Computes posterior P(A|B) given prior P(A), sensitivity P(B|A), and false-pos P(B|~A) */
double bayes_theorem(double prior, double sensitivity, double false_positive_rate) {
    double p_not_a = 1.0 - prior;
    double p_b = (sensitivity * prior) + (false_positive_rate * p_not_a);
    if (p_b <= 0.0) return 0.0;
    return (sensitivity * prior) / p_b;
}

int main(void) {
    double posterior = bayes_theorem(0.01, 0.99, 0.05);
    printf("Posterior P(Disease | Pos Test) = %.2f%%\n", posterior * 100.0);
    return 0;
}
def bayes_update(prior: float, sensitivity: float, false_pos_rate: float) -> float:
    """Calculates posterior P(Hypothesis | Evidence)."""
    p_evidence = (sensitivity * prior) + (false_pos_rate * (1 - prior))
    return (sensitivity * prior) / p_evidence

if __name__ == "__main__":
    posterior = bayes_update(prior=0.01, sensitivity=0.99, false_pos_rate=0.05)
    print(f"Posterior probability: {posterior * 100:.2f}%")
    # Output: Posterior probability: 16.67%

Check Your Understanding

Q1. In Bayes' Theorem, what does $P(A)$ represent?

The word "prior" literally means "before".
$P(A)$ is the prior probability, while $P(A|B)$ is the updated posterior probability.

Q2. What happens if the likelihood $P(B|A) = 1$ and $P(B|\neg A) = 0$ (a 100% infallible test)?

If evidence $B$ is physically impossible when $A$ is false ($P(B|\neg A) = 0$), can observing $B$ ever be a false positive?
With zero false positives, seeing $B$ guarantees hypothesis $A$ is true: $P(A|B) = 1$.

Q3. Failing to consider how rare a condition is when interpreting test results is known as:

Think about the base rate of the disease in the population.
The base rate fallacy occurs when people judge probability without accounting for how rare the base condition is.
