GCD & LCM

The Greatest Common Divisor (GCD) and Least Common Multiple (LCM) are fundamental building blocks of arithmetic, cryptography, and algorithm design, tied together by a direct product theorem.

The Formula

Product Duality Formula

$$\gcd(a,b) \cdot \operatorname{lcm}(a,b) = |a \cdot b| \implies \operatorname{lcm}(a,b) = \dfrac{|a \cdot b|}{\gcd(a,b)}$$

where $\gcd(a,b)$ is computed in $O(\log(\min(a,b)))$ steps using Euclid's remainder theorem: $\gcd(a,b) = \gcd(b, a \bmod b)$.

Symbol Definitions

SymbolMeaningDomain
a, bInput integersIntegers ($a, b \in \mathbb{Z}$), not both zero
gcd(a, b)Greatest common integer dividing both a and bPositive integer $\ge 1$
lcm(a, b)Smallest positive integer divisible by both a and bPositive integer $\ge \max(|a|, |b|)$
a mod bRemainder when integer a is divided by integer b$0 \le r < b$

Conditions & Assumptions

Key notes on number domain:
  • Both numbers cannot be simultaneously zero: $\gcd(0, 0)$ is undefined (any number divides 0).
  • If either number is 0 (e.g. $\gcd(a, 0)$), $\gcd(a, 0) = |a|$, while $\operatorname{lcm}(a, 0) = 0$.
  • Two integers $a, b$ are called coprime (or relatively prime) if $\gcd(a, b) = 1$. When this occurs, $\operatorname{lcm}(a, b) = a \cdot b$.

Plain-Language & Prime Factor Intuition

Consider the prime factorizations of two numbers. For each distinct prime factor $p$:

  • $\gcd(a, b)$ takes the minimum exponent of $p$: $\min(e_a, e_b)$.
  • $\operatorname{lcm}(a, b)$ takes the maximum exponent of $p$: $\max(e_a, e_b)$.

Because $\min(x, y) + \max(x, y) = x + y$ for any two powers, multiplying the GCD and LCM adds the exponents back together, recreating the exact product $a \cdot b$.

Worked Example

Problem

Find the GCD and LCM of 48 and 18 using the Euclidean Algorithm.

1
Divide 48 by 18.
$48 = 18 \times 2 + 12$. Remainder is 12.
2
Divide 18 by the remainder 12.
$18 = 12 \times 1 + 6$. Remainder is 6.
3
Divide 12 by the remainder 6.
$12 = 6 \times 2 + 0$. Remainder is 0. Since the remainder is zero, the divisor 6 is our GCD.
4
Compute LCM using the product duality theorem.
$\operatorname{lcm}(48, 18) = \dfrac{48 \times 18}{\gcd(48, 18)} = \dfrac{864}{6} = 144$.
✓ $\gcd(48, 18) = 6$ and $\operatorname{lcm}(48, 18) = 144$.

Code Examples

Fast Euclidean algorithms implemented with overflow protection when computing LCM.

#include <stdio.h>
#include <stdlib.h>

/* Efficient iterative Euclidean Algorithm */
long long gcd(long long a, long long b) {
    a = llabs(a);
    b = llabs(b);
    while (b != 0) {
        long long rem = a % b;
        a = b;
        b = rem;
    }
    return a;
}

/* LCM: divide before multiplying to prevent integer overflow */
long long lcm(long long a, long long b) {
    if (a == 0 || b == 0) return 0;
    return (llabs(a) / gcd(a, b)) * llabs(b);
}

int main(void) {
    long long a = 48, b = 18;
    printf("GCD(%lld, %lld) = %lld\n", a, b, gcd(a, b));
    printf("LCM(%lld, %lld) = %lld\n", a, b, lcm(a, b));
    return 0;
}
import math

def euclidean_gcd(a: int, b: int) -> int:
    """Computes the Greatest Common Divisor using Euclid's loop."""
    a, b = abs(a), abs(b)
    while b:
        a, b = b, a % b
    return a

def compute_lcm(a: int, b: int) -> int:
    """Computes the Least Common Multiple using the duality formula."""
    if a == 0 or b == 0:
        return 0
    return (abs(a) // euclidean_gcd(a, b)) * abs(b)

if __name__ == "__main__":
    x, y = 48, 18
    print(f"GCD({x}, {y}) =", euclidean_gcd(x, y))
    print(f"LCM({x}, {y}) =", compute_lcm(x, y))
    # In Python 3.9+, math.gcd and math.lcm are built-in!

Check Your Understanding

Q1. What is $\gcd(17, 31)$?

Both 17 and 31 are distinct prime numbers.
Since both 17 and 31 are prime, their only common divisor is 1. Thus $\gcd(17, 31) = 1$.

Q2. Two numbers $a$ and $b$ have a product of $a \times b = 300$, and their $\gcd(a, b) = 5$. What is their $\operatorname{lcm}(a, b)$?

Use the duality formula: $\operatorname{lcm}(a, b) = (a \cdot b) / \gcd(a, b) = 300 / 5$.
$\operatorname{lcm}(a,b) = 300 / 5 = 60$. Notice that $5 \times 60 = 300$.

Q3. What is the greatest common divisor $\gcd(24, 36)$?

Prime factorize: $24 = 2^3 \times 3$ and $36 = 2^2 \times 3^2$. Take minimum powers.
$\min(2^3, 2^2) = 2^2 = 4$ and $\min(3^1, 3^2) = 3$. So $\gcd = 4 \times 3 = 12$.
